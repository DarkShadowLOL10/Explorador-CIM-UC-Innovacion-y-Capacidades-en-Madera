# 02. Requerimientos de alto nivel

## Propuesta: Explorador CIM UC

Estos requerimientos describen las capacidades generales de la solución, sin definir todavía detalles técnicos de implementación.

| ID | Requerimiento de alto nivel | Prioridad |
|---|---|---|
| RAL-01 | La aplicación deberá permitir explorar una muestra de contenidos del CIM UC desde una experiencia móvil y responsive. | Must |
| RAL-02 | La aplicación deberá permitir buscar contenidos mediante palabras clave. | Must |
| RAL-03 | La aplicación deberá permitir filtrar contenidos por tipo o categoría. | Must |
| RAL-04 | La aplicación deberá permitir consultar el detalle de cada contenido seleccionado. | Must |
| RAL-05 | La aplicación deberá permitir identificar relaciones entre proyectos, capacidades, integrantes, publicaciones y actividades. | Must |
| RAL-06 | La aplicación deberá orientar a la persona usuaria hacia formación u oportunidades de colaboración. | Should |
| RAL-07 | La aplicación deberá permitir expresar interés mediante un mecanismo de contacto simulado. | Must |
| RAL-08 | La aplicación deberá representar opcionalmente una firma electrónica avanzada o e-token como simulación académica. | Could |
| RAL-09 | La aplicación deberá utilizar datos ficticios, sintéticos, públicos o anonimizados. | Must |
| RAL-10 | La aplicación deberá ser utilizable desde teléfonos, tablets y computadores con una interfaz adaptable. | Must |

## Flujo principal de solución

**Explorar -> buscar o filtrar -> consultar detalle -> revisar relaciones -> contactar -> confirmar solicitud simulada**

## Priorización del MVP

El flujo mínimo demostrable estará compuesto por `RAL-01` a `RAL-05`, `RAL-07`, `RAL-09` y `RAL-10`. La simulación de firma electrónica se incorporará como complemento del formulario de contacto.
